# CYP2D6-Stratified PK/PD Analysis

This analysis compares pharmacokinetic exposure and pharmacodynamic responses
between Extensive, Intermediate, and Slow CYP2D6 phenotypes. The Slow group
contains one participant, so the three-level result is descriptive; the main
inferential comparison combines Intermediate and Slow into a Reduced group.

- [R analysis script](PKPD_CYP_Stratified.r)
- [Analysis report](PKPD_CYP_Stratified.md)

Methods include non-compartmental exposure summaries, mixed-effects models,
estimated marginal means, exposure-response models, and Benjamini-Hochberg
adjustment.
