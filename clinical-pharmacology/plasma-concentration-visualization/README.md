# Plasma Concentration Visualization

Interactive React visualization of repeated-dose plasma concentration profiles.
The component uses a one-compartment model with first-order absorption and
elimination and supports two-drug comparison, missed doses, and double doses.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

The app uses synthetic parameter values and does not require clinical data.
